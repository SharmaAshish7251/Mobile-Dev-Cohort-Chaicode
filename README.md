## Project structure

This repository is organized to keep the Expo app and your assignment work easy to find.

```text
Mobile-Dev-Cohort-Chaicode/
├─ app.json
├─ package.json
├─ tsconfig.json
├─ app/
├─ assets/
│  └─ images/
│     └─ tabIcons/
└─ src/
   └─ app/
      ├─ _layout.tsx
      ├─ Basic_components.tsx
      ├─ Colors.tsx
      ├─ index.tsx
      └─ assignments/
         └─ Assignment.tsx
```

> The `src/app/assignments` folder is where assignment files and exercises belong.
> FontAwesome and Ionicons used
> KeyboardAvoidingView, used custom logo, expo,no external library used for Design.
> responsive for mobile screens
